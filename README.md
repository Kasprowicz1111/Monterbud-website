# MONTERBUD

Oficjalna strona internetowa firmy przemysłowej MONTERBUD z Nowego Miasta Lubawskiego.

## Technologie

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- GSAP
- Lucide React

## Uruchomienie

```bash
npm install
npm run dev
```

Produkcyjny build:

```bash
npm run build
npm start
```
